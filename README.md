# Java POO - Fundamentos

Repositório dedicado aos meus estudos e exercícios práticos de Programação Orientada a Objetos em Java.

## Objetivo

Fortalecer minha base em POO antes de avançar nos estudos de Spring Boot.

## Conteúdos

- Classes e objetos
- Construtores e this
- Encapsulamento
- Getters e setters
- Relacionamento e dependência entre classes
- Injeção de dependência
- Interfaces
- Herança
- Polimorfismo
- Collections
- Exceções

## Organização

Os exercícios serão organizados em pastas conforme minha evolução nos estudos.
